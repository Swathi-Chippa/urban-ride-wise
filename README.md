# Smart City Transit

Build a modern city public transit optimization web application named "TransitBrain AI" with two main views:

1. Operator Dashboard (Dark Theme):

- An interactive map displaying bus routes, live bus markers, and demand heatmaps.

- A "City Signals Simulation" top bar with toggle buttons: "College Exam Ends", "Heavy Rain", and "Concert Surge".

- An "AI Agent Activity Log" sidebar that updates when signals are toggled.

2. Passenger View (Mobile Frame):

- Destination selector.

- "Recommended Best Bus for You" card highlighting lowest predicted crowding, ETA, and accessibility options, followed by alternative buses.

Include a top navigation bar to toggle between "Operator View" and "Passenger View".
